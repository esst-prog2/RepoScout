| 7 | Publish setup: the deploy workflow and docs (tasks 4, 5.1) | Looked up the current release of each official GitHub Pages action and pinned them exactly (checkout v7.0.1, setup-python v7.1.0, setup-node v7.1.0, configure-pages v6.0.0, upload-pages-artifact v5.0.0, deploy-pages v5.0.1).
